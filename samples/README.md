# Sample receipts

Made-up Dutch receipts for testing receipt reading (slice 3). The suppliers, addresses and
KvK/VAT numbers are fictional. Everything here is generated by `node scripts/make-samples.ts`
(it uses the Playwright Chromium), so the images and their expected answers always match.

Each `<name>.expected.json` is the answer the reader should give, in the JSON shape from
CLAUDE.md ("Receipt extraction"), with prices incl. VAT, plus:
- `needsReview: true` when the receipt can't add up (06: one line is hidden under a fold);
- `{ "error": "not_a_receipt" }` when there is nothing to read (07: card slip only, 08: shopping list);
- `note`: what the sample tests.

`measure`/`unit` follow one rule: a measure is given only when the receipt states it
(a count bought per piece, a pack size like "200ST", or a size like "25KG" or "4M" times the
quantity). Anything else, or a unit Bonnetje doesn't have (m²), is `null`.

Real receipts can be added next to these with their own `.expected.json`.
